# 커스텀 꽃다발 이미지 생성 기능

## 개요

사용자가 원하는 꽃과 포장을 선택하면 AI가 실제 꽃다발 이미지를 생성해주고, 마음에 들면 해당 이미지 그대로 주문할 수 있는 기능입니다.

- **페이지 URL**: `/custom`
- **브랜치**: `feature/bouquet-image-generation`

---

## 주요 기능

### 1. 꽃 선택
- **메인 꽃 설정**: 꽃 카드를 클릭하면 메인 꽃으로 지정 (⭐ 배지 표시). 메인 꽃이 AI 이미지의 중심이 됨
- **추가 꽃 선택**: +/- 버튼으로 꽃 종류별 수량 조절 (최대 5송이)
- **색상 필터**: 레드 / 핑크 / 화이트 / 옐로우 / 퍼플 / 오렌지 / 블루 / 그린으로 필터링
- **그룹별 표시**: 같은 종류의 꽃은 색상별로 묶어서 섹션 헤더와 함께 표시

### 2. 포장 선택
| 옵션 | 추가 금액 |
|------|----------|
| 크라프트지 | +2,000원 |
| 리본 장식 | +3,000원 |
| 레이스 포장 | +4,000원 |
| 미니멀 포장 | +1,500원 |

### 3. AI 이미지 생성
- 메인 꽃 설정 + 꽃 1송이 이상 선택 시 "꽃다발 이미지 생성하기" 버튼 활성화
- **AI 서비스**: [Pollinations.ai](https://pollinations.ai) — 무료, API 키 불필요
- **모델**: `flux-realism` (사실적인 꽃 사진에 최적화)
- 이미지 생성 중 로딩 스피너 표시, 완료 후 미리보기 패널에 표시
- 생성 실패 시 에러 안내 + 재생성 가능
- 꽃 선택 변경 시 기존 이미지 자동 초기화

### 4. 주문
- 이미지 생성 전: "장바구니 담기" (rose 버튼)
- 이미지 생성 후: "이 꽃다발로 주문하기" (amber 버튼) → 생성 이미지 포함하여 장바구니에 추가 후 `/cart`로 이동

---

## 가격 구조

```
기본 포장재: 10,000원
+ 선택한 꽃 수량 × 단가
+ 포장 방식 추가 금액
= 합계
```

---

## 구현 파일

| 파일 | 역할 |
|------|------|
| `app/(shop)/custom/page.tsx` | 메인 UI — 꽃 선택, 이미지 생성, 주문 |
| `app/api/custom/generate-image/route.ts` | OpenAI DALL-E 3 API 라우트 (현재 미사용, 예비) |
| `public/flowers/` | 꽃 썸네일 이미지 47개 |
| `next.config.ts` | Pollinations.ai 도메인 remotePatterns 추가 |

> **참고**: 현재 이미지 생성은 Pollinations.ai를 직접 호출 (프론트엔드). `generate-image/route.ts`는 향후 OpenAI DALL-E 3으로 전환 시 사용 예정.

## AI 프롬프트 구조

```
Professional Korean florist bouquet photograph,
featuring {수량} {메인꽃 영문설명}, {수량} {추가꽃 영문설명}, ... as the focal arrangement,
{포장방식},
studio lighting, pure white background, top-down flat lay angle,
sharp focus, highly detailed, photorealistic

[네거티브 프롬프트]
cartoon, illustration, painting, text, watermark, people, hands, vase, blurry, extra flowers not mentioned
```

- 꽃 이름은 색상·형태 포함 영문 상세 설명으로 전달 (예: `"red roses with deep velvety petals"`)
- 수량 명시로 구성 비율 제어
- `seed=Date.now()` 로 재생성 시마다 다른 이미지 생성

## 알려진 이슈 및 주의사항

- **이미지 생성 속도**: Pollinations.ai는 무료 서비스로 생성에 10~30초 소요. 상용 전환 시 OpenAI DALL-E 3 또는 Fal.ai 검토 필요
- **안개꽃 파일명**: `baby's_breath`에 아포스트로피 포함 → img src에서 `%27`로 URL 인코딩 처리
- **이미지 캐시**: 정적 파일(`public/flowers/`) 변경 후 브라우저에서 `Ctrl+Shift+R` 강력 새로고침 필요
- **Pollinations.ai 제한**: 동시 요청 과다 시 간헐적 생성 실패 가능 → 재생성 버튼으로 재시도
