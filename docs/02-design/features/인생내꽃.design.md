## 1. DB 스키마 (Prisma)

```prisma
// prisma/schema.prisma

generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

// ─── 사용자 ───────────────────────────────────────────

model User {
  id            String    @id @default(cuid())
  email         String    @unique
  name          String?
  image         String?
  birthDate     DateTime? // 사주 분석용 생년월일
  calendarType  String?   @default("solar") // "solar" | "lunar"
  ohaengType    String?   // 오행 유형 캐시: "목" | "화" | "토" | "금" | "수"
  createdAt     DateTime  @default(now())

  accounts      Account[]
  orders        Order[]
  cartItems     CartItem[]
  wishlist      WishlistItem[]
  reviews       Review[]
  subscriptions Subscription[]
}

model Account {
  id                String  @id @default(cuid())
  userId            String
  provider          String  // "kakao" | "google"
  providerAccountId String
  user              User    @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@unique([provider, providerAccountId])
}

// ─── 상품 ───────────────────────────────────────────

model Product {
  id          String   @id @default(cuid())
  name        String
  description String
  price       Int      // 원 단위
  stock       Int      @default(0)
  category    String   // "bouquet" | "plant" | "wreath" | "dried" | "subscription"
  images      String[] // Vercel Blob URL 배열
  flowerMeaning String? // 꽃말
  ohaengTags  String[] // 연관 오행: ["목", "화"]
  seasonTags  String[] // 계절: ["spring", "summer"]
  colorTags   String[] // 색상: ["red", "white", "pink"]
  isActive    Boolean  @default(true)
  createdAt   DateTime @default(now())

  cartItems    CartItem[]
  orderItems   OrderItem[]
  wishlist     WishlistItem[]
  reviews      Review[]
  customBases  CustomBase[] // 꽃다발 커스텀 베이스로 사용 가능한 상품
}

// ─── 장바구니 ────────────────────────────────────────

model CartItem {
  id        String  @id @default(cuid())
  userId    String
  productId String
  quantity  Int     @default(1)
  options   Json?   // 선물 포장 옵션 등

  user    User    @relation(fields: [userId], references: [id], onDelete: Cascade)
  product Product @relation(fields: [productId], references: [id])

  @@unique([userId, productId])
}

// ─── 주문 ───────────────────────────────────────────

model Order {
  id            String      @id @default(cuid())
  userId        String
  status        OrderStatus @default(PENDING)
  totalAmount   Int
  shippingFee   Int         @default(0)
  deliveryType  String      // "standard" | "same_day" | "reserved"
  deliveryAt    DateTime?   // 예약 배송일
  shippingAddr  Json        // { name, phone, address, detail, zipcode }
  giftMessage   String?
  giftWrapping  Boolean     @default(false)
  paymentId     String?     // 포트원 결제 ID
  paymentMethod String?     // "card" | "kakao_pay" | "toss_pay"
  qrCode        String?     // 포토부스 QR 코드 값
  createdAt     DateTime    @default(now())

  user      User        @relation(fields: [userId], references: [id])
  items     OrderItem[]
}

enum OrderStatus {
  PENDING      // 결제 대기
  PAID         // 결제 완료
  PREPARING    // 상품 준비 중
  SHIPPED      // 배송 중
  DELIVERED    // 배송 완료
  CANCELLED    // 취소
}

model OrderItem {
  id        String @id @default(cuid())
  orderId   String
  productId String
  quantity  Int
  price     Int    // 주문 시점 가격 스냅샷

  order   Order   @relation(fields: [orderId], references: [id])
  product Product @relation(fields: [productId], references: [id])
}

// ─── 위시리스트 ──────────────────────────────────────

model WishlistItem {
  id        String   @id @default(cuid())
  userId    String
  productId String
  createdAt DateTime @default(now())

  user    User    @relation(fields: [userId], references: [id], onDelete: Cascade)
  product Product @relation(fields: [productId], references: [id])

  @@unique([userId, productId])
}

// ─── 리뷰 ───────────────────────────────────────────

model Review {
  id        String   @id @default(cuid())
  userId    String
  productId String
  rating    Int      // 1~5
  content   String
  images    String[] // 포토 리뷰 이미지
  createdAt DateTime @default(now())

  user    User    @relation(fields: [userId], references: [id])
  product Product @relation(fields: [productId], references: [id])
}

// ─── 구독 ───────────────────────────────────────────

model Subscription {
  id          String             @id @default(cuid())
  userId      String
  cycle       SubscriptionCycle  // 주 1회, 격주, 월 1회
  status      SubscriptionStatus @default(ACTIVE)
  nextDelivery DateTime
  preferences Json?              // 취향: { colors, styles }
  createdAt   DateTime           @default(now())

  user User @relation(fields: [userId], references: [id])
}

enum SubscriptionCycle {
  WEEKLY
  BIWEEKLY
  MONTHLY
}

enum SubscriptionStatus {
  ACTIVE
  PAUSED
  CANCELLED
}

// ─── 꽃다발 커스텀 ───────────────────────────────────

model CustomBase {
  id          String  @id @default(cuid())
  productId   String  @unique // 커스텀 베이스로 사용되는 상품
  basePrice   Int
  maxFlowers  Int     @default(5) // 최대 추가 꽃 수

  product Product      @relation(fields: [productId], references: [id])
  options CustomOption[]
}

model CustomOption {
  id         String @id @default(cuid())
  baseId     String
  flowerName String
  color      String
  addPrice   Int    // 추가 가격
  imageUrl   String // 꽃 PNG 이미지 (Canvas 합성용)

  base CustomBase @relation(fields: [baseId], references: [id])
}
```

## 2. API Routes 설계

### 사주·오행 분석

| Method | Path | 설명 |
|--------|------|------|
| POST | `/api/saju/analyze` | 생년월일 → 오행 분석 + 꽃 추천 반환 |

```typescript
// POST /api/saju/analyze
// Request
{ birthDate: "1995-03-15", calendarType: "solar" }

// Response
{
  ohaeng: "목",
  description: "목(木)의 기운은 성장과 생명력을 상징합니다.",
  recommendedFlowers: [
    { productId: "...", name: "청초한 튤립 다발", flowerMeaning: "사랑의 고백", imageUrl: "..." },
    { productId: "...", name: "초록빛 수국 화분", flowerMeaning: "진심", imageUrl: "..." }
  ],
  seasonalFlowers: [...] // 현재 계절 꽃 추가 추천
}
```

### 상품

| Method | Path | 설명 |
|--------|------|------|
| GET | `/api/products` | 상품 목록 (query: category, ohaeng, season, color, page) |
| GET | `/api/products/[id]` | 상품 상세 |

### 장바구니

| Method | Path | 설명 |
|--------|------|------|
| GET | `/api/cart` | 내 장바구니 조회 |
| POST | `/api/cart` | 상품 추가 |
| PATCH | `/api/cart/[id]` | 수량 변경 |
| DELETE | `/api/cart/[id]` | 상품 제거 |

### 주문·결제

| Method | Path | 설명 |
|--------|------|------|
| POST | `/api/orders` | 주문 생성 (결제 전) |
| POST | `/api/payment/verify` | 포트원 결제 검증 + 주문 확정 |
| GET | `/api/orders` | 내 주문 목록 |
| GET | `/api/orders/[id]` | 주문 상세 |

### 꽃다발 커스텀

| Method | Path | 설명 |
|--------|------|------|
| GET | `/api/custom/bases` | 커스텀 가능한 베이스 상품 목록 |
| GET | `/api/custom/bases/[id]/options` | 해당 베이스의 추가 꽃 옵션 |
| POST | `/api/custom/price` | 선택한 옵션 기반 가격 계산 |

### QR 코드 (포토부스)

| Method | Path | 설명 |
|--------|------|------|
| GET | `/api/orders/[id]/qr` | 주문 QR 코드 생성 |
| GET | `/api/photobooth/[qrCode]` | QR 인식 후 주문 정보 반환 |

### 관리자

| Method | Path | 설명 |
|--------|------|------|
| GET/POST | `/api/admin/products` | 상품 목록 조회 / 신규 등록 |
| PATCH/DELETE | `/api/admin/products/[id]` | 상품 수정 / 삭제 |
| GET | `/api/admin/orders` | 전체 주문 목록 |
| PATCH | `/api/admin/orders/[id]/status` | 주문 상태 변경 |

## 4. 핵심 로직 설계

### 4-1. 오행 분석 로직 (`lib/saju.ts`)

천간(天干) 10개의 오행 매핑을 기반으로 생년의 천간을 도출해 오행을 결정하는 단순화 규칙 적용.

```typescript
// 연도 끝 자리 → 천간 → 오행 매핑
const YEAR_OHAENG: Record<number, string> = {
  4: "목", 5: "목",
  6: "화", 7: "화",
  8: "토", 9: "토",
  0: "금", 1: "금",
  2: "수", 3: "수",
}

export function analyzeOhaeng(birthDate: Date): string {
  const year = birthDate.getFullYear()
  return YEAR_OHAENG[year % 10]
}

// 오행별 연관 꽃 색상 및 키워드
const OHAENG_PROFILE = {
  목: { colors: ["green", "blue"], keywords: ["성장", "생명력"], season: "spring" },
  화: { colors: ["red", "orange"], keywords: ["열정", "활력"], season: "summer" },
  토: { colors: ["yellow", "beige"], keywords: ["안정", "풍요"], season: "all" },
  금: { colors: ["white", "silver"], keywords: ["순수", "결실"], season: "autumn" },
  수: { colors: ["black", "purple"], keywords: ["지혜", "깊이"], season: "winter" },
}
```

### 4-2. SNS 공유 카드 생성 (`components/saju/ShareCard.tsx`)

`html2canvas`로 DOM 요소를 이미지로 변환 후 다운로드 또는 Web Share API로 공유.

```typescript
// 카드 생성 흐름
1. ShareCard 컴포넌트를 숨겨진 div로 렌더링 (1080×1080px)
2. html2canvas로 캡처 → Blob 생성
3. navigator.share({ files: [imageFile] }) 로 공유
   → 미지원 시 다운로드 링크 fallback
```

**카드 구성 요소**:
- 배경: 추천 꽃 이미지 (블러 처리)
- 오행 뱃지 + 꽃말 텍스트
- "인생내꽃" 로고 + 플랫폼 URL

### 4-3. 꽃다발 커스텀 미리보기 (`components/custom/FlowerCanvas.tsx`)

```typescript
// Canvas 렌더링 흐름
1. 베이스 상품 이미지를 배경으로 그리기
2. 선택한 꽃 옵션 PNG를 순서대로 canvas에 합성
3. 수량·위치는 미리 정의된 배치 좌표 사용
   (꽃 5개 → 고정 포지션 5개 중 채우기)
```

### 4-4. 결제 플로우 (포트원 V2)

```
[checkout/page.tsx]
  1. POST /api/orders → orderId 생성 (status: PENDING)
  2. PortOne.requestPayment({ orderId, amount, ... }) 호출
  3. 결제 완료 callback → POST /api/payment/verify
     - 서버에서 포트원 API로 결제 금액 검증
     - 검증 통과 → Order.status = PAID, 재고 차감 (트랜잭션)
     - QR 코드 생성 (nanoid) → Order.qrCode 저장
  4. 성공 → /mypage/orders/[id] 리다이렉트
```

### 4-5. 포토부스 QR 연동

```
[오프라인 포토부스 태블릿]
  1. 웹 카메라로 QR 스캔 (jsQR 라이브러리)
  2. GET /api/photobooth/[qrCode] 호출
  3. 응답: { orderId, customerName, productImages[] }
  4. 포토부스 화면에 구매한 꽃 이미지 배경으로 표시
  5. 촬영 진행
```

## 6. 인증 설계 (NextAuth.js v5)

```typescript
// lib/auth.ts
export const { handlers, auth, signIn, signOut } = NextAuth({
  providers: [
    KakaoProvider({
      clientId: process.env.KAKAO_CLIENT_ID,
      clientSecret: process.env.KAKAO_CLIENT_SECRET,
    }),
    GoogleProvider({
      clientId: process.env.GOOGLE_CLIENT_ID,
      clientSecret: process.env.GOOGLE_CLIENT_SECRET,
    }),
  ],
  adapter: PrismaAdapter(prisma),
  callbacks: {
    session: ({ session, user }) => ({
      ...session,
      user: { ...session.user, id: user.id },
    }),
  },
})
```

**보호 라우트**: `/mypage/*`, `/checkout`, `/admin/*` → middleware.ts에서 미인증 시 `/api/auth/signin` 리다이렉트
