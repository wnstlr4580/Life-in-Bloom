# 꽃다발 만들기 시연·테스트 가이드

운영 서버(life-in-bloom-plum.vercel.app)의 실제 재고·판매처 데이터로 2026-10-07에 확인한 결과다.
판매처 재고는 seed 테스트 데이터이므로, 데이터를 바꾸면 결과도 달라진다.

## 1. 고를 수 있는 꽃 (현재 재고 20종)

빨간·핑크·흰·노란 장미 / 핑크·흰·보라 튤립 / 흰·핑크 백합 / 파란·핑크 수국 /
빨간·핑크 카네이션 / 노란·주황 거베라 / 흰·핑크 안개꽃 / 프리지아 / 유칼립투스 / 해바라기

`/diy`에는 판매처에 재고가 있는 꽃만 나온다. 위 목록에 없는 꽃(작약, 아네모네 등)은 보이지 않는 게 정상이다.

## 2. 검증된 시연 조합

꽃 사진을 누르면 아래 송이 수로 자동 배분된다(첫 꽃이 메인).

| 크기 | 조합 (탭 순서대로) | 주문제작·전국배송 판매처 | 직접 만들기 (서대문구 기준 5km) |
|---|---|---|---|
| 미니 7송이 | 빨간 장미 → 흰 안개꽃 (4+3) | 13곳 · 27,900~31,960원 | 6곳 · 17,900~20,805원 |
| 기본 12송이 | 핑크 장미 → 핑크 카네이션 → 흰 안개꽃 (6+3+3) | 10곳 · 38,500~46,435원 | 4곳 · 30,075~35,595원 |
| 기본 12송이 | 해바라기 → 프리지아 → 유칼립투스 (6+3+3) | 6곳 · 36,400~44,095원 | 4곳 |
| 풍성 18송이 | 흰 장미 → 흰 백합 → 유칼립투스 → 흰 안개꽃 (9+3+3+3) | 14곳 · 57,400~72,415원 | 4곳 |
| 대형 25송이 | 빨간 장미 → 핑크 장미 → 빨간 카네이션 → 흰 안개꽃 → 유칼립투스 (12+4+3+3+3) | 2곳 · 87,875~89,200원 | 2곳 |

- **주문제작**: 위치 입력 없이 바로 "가능한 판매처·가격 확인"을 누르면 된다. 전국배송 판매처가 먼저 나온다.
- **직접 만들기**: 위치가 필요하다. 시연장에서 GPS가 불안하면 "도로명주소 검색"으로 `서울 서대문구 연희로 248`을 입력한다(판매처가 가장 많이 잡히는 지점).
- 대형처럼 꽃 종류가 많을수록 모든 꽃을 다 가진 판매처가 줄어든다. 판매처를 많이 보여주려면 미니~풍성이 안전하다.

## 3. 가격·데이터 출처

| 화면 표시 | 출처 | 팩트 여부 |
|---|---|---|
| 꽃 카드 "참고가 ○원/송이", 우측 "기본 참고가" | `lib/customFlowers.ts`에 고정된 값 (장미 3,000원 등) | 시세가 아닌 **서비스 내부 참고값** |
| 판매처별 "직접 만들기" 가격 | 판매처가 등록한 재고 단가(`SellerStock.unitPrice`) 합계 | 구조는 실제와 같음. 현재 값은 **seed 테스트 데이터** |
| 판매처별 "주문제작" 가격 | 위 재고 단가 합계 + 제작비 10,000원(고정) | 제작비는 **코드에 고정된 값** |
| 화훼공판장 위치·예상가 | aT 화훼유통정보시스템 공식 자료 (양재: 당일 경매 API, 그 외: 최근 7일 일자별 경매결과 파일을 매일 13시 수집) | **실제 경매 데이터**. 다만 선택한 색이 아니라 품목 전체 품종·등급의 속당 가중평균이고, 1속 본수는 관행 참고치(장미 10본 등). 공판장 좌표는 운영자가 수동 입력 |

공판장은 최근 7일 안에 해당 품목의 가격 자료가 있는 곳만 지도에 나온다. 2026-10-07 확인 시
양재·과천·고양 공판장 자료가 없어 서울에서 조회해도 광주·김해·부산 공판장만 표시됐다.
→ Vercel의 `/api/cron/public-market-prices` 실행 기록 확인 필요.

## 4. AI 꽃다발 이미지

- 모델: Cloudflare Workers AI `flux-1-schnell` (무료 한도 있음, 1장 20~60초)
- 크기별 모양(미니 → 대형 볼륨)과 포장지는 반영된다.
- **송이 수는 정확하지 않다.** 약 10송이 이하는 비슷하게, 그 이상은 실제보다 많게 그려지는 경향이 있다. 화면에 "송이 수는 실제와 다를 수 있어요" 안내를 표시한다.
- 시연 전에 사용할 조합으로 미리 생성해 두고, 결과가 좋은 이미지를 발표자료에 쓰는 것을 권장한다. 동시에 여러 장을 요청하면 시간 초과가 날 수 있다.

## 5. 시연 전 체크리스트

1. PC에서 `node scripts/demo-data-cleanup.mjs audit` → `apply` 실행 (테스트대표·테스트은행·"1km 꽃시장" 같은 문구 정리)
2. 위 조합 중 시연할 것 1~2개를 운영 서버에서 미리 한 번씩 실행 (이미지 생성 한도·속도 확인)
3. 키오스크는 카메라가 안 되면 주소 끝에 `?demo`를 붙여 테스트 사진 합성 버튼을 켠다
4. 결제는 "결제 건너뛰기(테스트용)" 체크로 진행 (실서비스 전 서버 측 결제 검증 보완 필요)
