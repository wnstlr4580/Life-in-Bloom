## 메뉴별 입력 조건
- 꽃 & 식물: 검색창에 "고양 장미농원" → 상품 카드에 농협 마크 + "조합원농가"
- 선물·용도별: 생일, 축하 (개업·결혼은 상품 4개뿐)
- 나의 꽃 찾기: 생년월일 + 성별 (이름·태어난 시간은 선택)
- 궁합 보기: 두 사람 이름 + 생년월일
- 오행 포토부스: /kiosk?demo → 구매한 꽃으로 찍기 → 바코드 2001000000111 (해바라기)
  - 다른 바코드: 2001000000012 빨간 장미 / 2001000000050 핑크 튤립 / 2001000000081 파란 수국
  - 카메라가 없으면 촬영 화면의 "테스트 사진으로 합성" 버튼
- 꽃다발 만들기: 기본 크기 → 핑크 장미, 핑크 카네이션, 흰 안개꽃 순서로 탭
  - 주문제작: 바로 "가능한 판매처·가격 확인"
  - 직접 만들기: 주소 "서울 서초구 강남대로 27", 검색 거리 5km → 농협 K플라워마트 양재점 포함
- 장바구니·결제: 일반회원 로그인 → 결제 화면에서 "결제 건너뛰기" 체크
- 주문 조회: 주문번호 + 주문 시 입력한 연락처
- 후기 작성: 마이페이지에서 구매확정한 주문만 가능
- 판매자센터: kflowermart 로그인 → 개별 꽃 재고 → 꽃마다 바코드 확인·수정
- 관리자센터 → 판매처 관리 (조합원 심사)
  - 이천 꽃농원: ① 조합원 확인 통과 → ② 교육이력 없음 → 반려
  - 일산 오늘꽃집: ① 조합원 아님
  - 고양 장미농원: 이미 승인된 조합원농가
