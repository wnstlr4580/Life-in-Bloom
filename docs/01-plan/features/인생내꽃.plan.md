# [Plan] 인생내꽃

> 한국화훼농협 케이플라워(K-Flower) 쇼핑몰의 신규 플랫폼 제안 — 사주·오행 기반 개인화 꽃 추천 + SNS 공유 + 오프라인 포토부스 연계 감성 커머스

---

## 1. 개요 (Overview)

### 배경 및 방향 전환

기존 케이플라워 쇼핑몰은 40~50대 중심의 단순 카탈로그 나열 방식으로 운영되어 왔으나, 유통기한·배송 난이도 등 소매 직배송 한계가 명확하다.  
인생내꽃은 20~40대 MZ세대를 타겟으로, **사주·오행 기반 개인화 추천**과 **SNS 감성 공유**를 핵심으로 하는 신규 플랫폼을 제안한다.

### 기존 vs 인생내꽃 비교

| 구분 | 기존 케이플라워 | 인생내꽃 (제안) |
|------|---------------|----------------|
| 타겟 | 40~50대 중심 | 20~40대 / MZ세대 |
| 추천 방식 | 단순 카탈로그 나열 | 사주·꽃말·계절 기반 개인화 추천 |
| UX | 노후화된 UI | 감성 중심 모던 디자인 |
| SNS 연동 | 없음 | 인스타그램 꽃 카드 공유 기능 |
| 오프라인 연계 | 없음 | 케이플라워 마트 포토부스 연동 |

### 핵심 플로우

```
[생년월일 입력] → [오행 분석] → [꽃말·계절 연계 꽃 추천]
     ↓
[꽃다발 커스텀] → [실시간 미리보기] → [구매 또는 SNS 공유]
     ↓
[오프라인 포토부스 QR 인식] → [구매 꽃 배경 인생네컷 촬영]
```

## 2. 핵심 기능 (Core Features)

### Feature A: 사주 기반 꽃 추천

생년월일 입력 → 오행(목·화·토·금·수) 분석 → 꽃말과 계절에 연계된 꽃 추천.

| 단계 | 내용 |
|------|------|
| 입력 | 생년월일 (양력/음력 선택) |
| 분석 | 오행 유형 도출 (목·화·토·금·수) |
| 추천 | 오행별 대표 꽃 + 계절 꽃 + 꽃말 설명 |
| 출력 | 추천 꽃다발 구성 + 구매 연결 |

### Feature B: 꽃다발 커스텀

| 기능 | 설명 |
|------|------|
| 색상 기반 구성 | 원하는 색상 선택 → 어울리는 꽃 조합 |
| 실시간 이미지 미리보기 | 선택한 꽃 조합을 실시간으로 시각화 |
| 예상 가격 제공 | 구성에 따른 실시간 가격 계산 |
| 구매 연결 | 커스텀 결과 → 장바구니 직접 추가 |

### Feature C: SNS 공유 (인스타그램 꽃 카드)

| 기능 | 설명 |
|------|------|
| 카드 생성 | 사주 결과 + 추천 꽃을 배경 카드로 제작 |
| 공유 | 인스타그램 스토리/피드 링크 공유 |
| 바이럴 유입 | 카드에 플랫폼 링크 포함 → 자연 유입 |

### Feature D: 오프라인 포토부스 연동

| 기능 | 설명 |
|------|------|
| QR 코드 인식 | 케이플라워 마트 현장에서 QR 스캔 |
| 구매 꽃 배경 | 구매한 꽃을 배경으로 한 인생네컷 촬영 |
| 온·오프라인 연계 | 온라인 구매 → 오프라인 체험으로 연결 |

### Feature E: 기본 커머스 기능

| 기능 | 설명 |
|------|------|
| 상품 탐색 | 카테고리, 검색, 필터 |
| 장바구니 & 결제 | 포트원 결제 (카드, 카카오페이 등) |
| 회원 관리 | 소셜 로그인, 주문 내역, 위시리스트 |
| 배송 옵션 | 일반·당일·예약 배송, 선물 포장 |

## 3. 향후 발전 과제

- **오행 기반 지역 꽃 추천**: 대부분의 꽃이 하우스 재배로 산지 구분이 어려운 현실 확인 후, 로컬 플라워 농가와의 연계 방안 추후 검토
- **지역 로컬 플라워 방문 연결**: 지역 발전 자원에서 로컬 꽃 농가·꽃집과 플랫폼을 연결하는 방안 기획 예정

## 4. 기술 스택 (Tech Stack)

| 분류 | 선택 | 이유 |
|------|------|------|
| 프론트엔드 | Next.js 15 (App Router) | SSR/SSG로 SEO 최적화 |
| 스타일링 | Tailwind CSS + shadcn/ui | 빠른 감성 UI 구성 |
| 상태 관리 | Zustand | 장바구니, 커스텀 빌더 상태 |
| 백엔드 | Next.js API Routes | 풀스택 단일 프레임워크 |
| 데이터베이스 | PostgreSQL (Vercel Postgres) | 관계형 데이터 |
| ORM | Prisma | 타입 안전한 DB 접근 |
| 인증 | NextAuth.js v5 | 소셜 로그인 (카카오, 구글) |
| 파일 저장 | Vercel Blob | 상품 이미지, 꽃 카드 생성 이미지 |
| 결제 | 포트원 (PortOne) | 국내 결제 PG 통합 |
| 이미지 합성 | Canvas API / html2canvas | 꽃 카드 이미지 생성 |
| 배포 | Vercel | Next.js 최적화 |

## 6. 개발 단계 (Phases)

| Phase | 내용 | 목표 |
|-------|------|------|
| Phase 1 | 프로젝트 초기 설정 + DB 스키마 | Next.js 세팅, Prisma 스키마 |
| Phase 2 | 사주·오행 분석 + 꽃 추천 | 핵심 차별화 기능 |
| Phase 3 | 꽃다발 커스텀 빌더 | 실시간 미리보기 + 가격 계산 |
| Phase 4 | SNS 공유 카드 생성 | Canvas 기반 이미지 생성 |
| Phase 5 | 기본 커머스 (상품·장바구니·결제) | 포트원 결제 연동 |
| Phase 6 | 회원 관리 + 마이페이지 | NextAuth 소셜 로그인 |
| Phase 7 | 관리자 대시보드 | 상품·주문 관리 |
| Phase 8 | 오프라인 포토부스 QR 연동 | QR 생성·인식 |
| Phase 9 | 디자인 다듬기 + 배포 | Vercel 프로덕션 |

## 7. 성공 기준 (Success Criteria)

- [ ] 생년월일 입력 → 오행 분석 → 꽃 추천까지 끊김 없이 동작
